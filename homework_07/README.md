# Работа 7. Подбор масок

## Условие и расчёт

В первой задаче адресное пространство `192.168.0.0/24` нужно распределить между пятью сегментами, каждый минимум на 25 устройств. Префикс `/27` оставляет 30 адресов узлам; внутри исходной сети помещаются восемь таких блоков.

| Сегмент | Сеть | Адреса узлов | Broadcast |
|---:|---|---|---|
| 1 | `192.168.0.0/27` | `192.168.0.1–192.168.0.30` | `192.168.0.31` |
| 2 | `192.168.0.32/27` | `192.168.0.33–192.168.0.62` | `192.168.0.63` |
| 3 | `192.168.0.64/27` | `192.168.0.65–192.168.0.94` | `192.168.0.95` |
| 4 | `192.168.0.96/27` | `192.168.0.97–192.168.0.126` | `192.168.0.127` |
| 5 | `192.168.0.128/27` | `192.168.0.129–192.168.0.158` | `192.168.0.159` |

Для второй задачи требуется шесть сегментов из `192.168.50.0/24`. Маска также `/27` (`255.255.255.224`): каждый блок содержит 32 адреса, из которых 30 можно назначить узлам.

| Сегмент | Диапазон блока | Доступные адреса узлов |
|---:|---|---|
| 1 | `192.168.50.0–192.168.50.31` | `192.168.50.1–192.168.50.30` |
| 2 | `192.168.50.32–192.168.50.63` | `192.168.50.33–192.168.50.62` |
| 3 | `192.168.50.64–192.168.50.95` | `192.168.50.65–192.168.50.94` |
| 4 | `192.168.50.96–192.168.50.127` | `192.168.50.97–192.168.50.126` |
| 5 | `192.168.50.128–192.168.50.159` | `192.168.50.129–192.168.50.158` |
| 6 | `192.168.50.160–192.168.50.191` | `192.168.50.161–192.168.50.190` |
