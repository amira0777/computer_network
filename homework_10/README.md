# Работа 10. Уровень транспорта

Транспортные протоколы связывают приложения на разных устройствах. Порты позволяют операционной системе направить полученные данные нужной программе; сокет обычно описывается адресом узла и номером порта.

**TCP** сначала устанавливает соединение обменом SYN, SYN-ACK и ACK. Затем подтверждения, повторная передача потерянных сегментов и упорядочивание байтов помогают доставлять поток данных надежно. Скользящее окно позволяет не ждать подтверждения после каждого отдельного сегмента.

**UDP** отправляет самостоятельные дейтаграммы без предварительного соединения и не гарантирует доставку или порядок. Меньшие накладные расходы подходят приложениям, где важнее задержка и скорость реакции, чем повторная отправка каждого сообщения.

Итого: TCP чаще выбирают для целостной передачи файлов и страниц; UDP — для обмена небольшими запросами и чувствительных к задержке потоков.
